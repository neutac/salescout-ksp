# Наблюдение за карточками Kaspi.kz

Страница просит вход. Каждый пользователь видит только свои проверки. Администратор добавляет и отключает учётные записи и видит все проверки. Учётная запись администратора `root` создаётся при запуске из переменной `ADMIN_PASSWORD`. Вход подписывается отдельной переменной `SESSION_SECRET` длиной не короче 16 символов. Без неё страница не выдаёт сессию.

Страница ищет карточки по наименованию, сохраняет запрос, карточки и снимки склада с отзывами. Повтор проверки задаётся числом заходов и промежутком в минутах. Поиск можно остановить вручную. Новая запись по карточке появляется только когда изменились остаток, отзывы, оценки или состав продавцов.

Поиск идёт сразу по всем городам из списка Kaspi, а не только по Алматы. В обзор входят первые 12 разных карточек и города, где они нашлись. Остаток по карточке читается в первом таком городе.

## Страница

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cd web && npm install && npm run build && cd ..
.venv/bin/python -m uvicorn server:app --host 127.0.0.1 --port 8643
```

Откройте http://127.0.0.1:8643 . База SQLite создаётся в `data/kaspi.db`.

Во время разработки интерфейса можно поднять API на порту 8642 и Vite на 8643: Vite проксирует `/api`.

## Скрипт одной карточки

Скрипт читает публичные данные карточки товара и записывает их в `Results/<код товара>.json`.

На этой машине уже стоят Python 3.12, пакет `python3.12-venv`, библиотека `libcurl4` и сертификаты `ca-certificates`. Зависимость Python ставится в локальное окружение `.venv`.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python kaspi_card.py "https://kaspi.kz/shop/p/arnai-ar-1505-seryi-serebristyi-157451859/?c=750000000"
```

Файл результата: `Results/157451859.json`.

Поле `StockAvailable` — остаток склада. Скрипт спрашивает лимит заказа количествами 50, 100, 500 и дальше, пока сервер не вернёт остаток меньше запрошенного. Покупка при этом не подтверждается. `max_quantity` остаётся отдельным лимитом одного заказа. `reviews_by_merchant` — число отзывов этой карточки у каждого продавца по оценкам 1, 2, 3, 4 и 5. Продавец из текущего списка без отзывов тоже попадает в список с нулями.

Город берётся из параметра `c` ссылки. Если его нет, используется Алматы (`750000000`). Другой город: `--city 710000000`. Таймаут одного ответа по умолчанию 25 секунд (`--timeout`). После ответа 429 или обрыва по времени скрипт ждёт и повторяет тот же запрос до 3 раз (`--retries`). Заголовки при повторе не меняются.

## Прокси

Свой внешний прокси не нужен. Скрипт сам поднимает локальный SOCKS5 на `127.0.0.1` и пускает через него только `kaspi.kz` и его поддомены, порт 443. Адрес выхода в интернет не меняется. Прокси живёт, пока идёт сбор, и не прописан в системе как общий прокси.

Этот прокси не меняет внешний IP и не обходит ограничение частоты Kaspi. Если магазин отвечает 429, скрипт делает паузу и повторяет запрос. Смена заголовков здесь не используется: CORS к запросам Python не относится, а подмена заголовков не снимает лимит магазина.

Свой прокси, если он уже есть: `--proxy http://host:port`.
